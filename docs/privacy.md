# 개인정보처리방침

시행일: 2026년 10월 8일

개발자나 다른 회사로 보내지 않아요. 이 문서는 동계부가 어떤 정보를 다루고, 어디에 두고, 언제 지우는지 알려 드려요.

## 2. 한눈에 보기

- 가계부에 적은 내용과 설정은 **이 기기 안에만** 저장돼요.
- 개발자를 포함해 누구에게도 보내지 않아요. 서버가 따로 없어요.
- 광고, 사용 통계·분석 도구가 없고, 회원 가입이나 로그인도 없어요.
- 인터넷은 새 버전을 확인할 때만 써요(아래 [5. 인터넷을 쓰는 곳](#5-인터넷을-쓰는-곳)).

### 결제 알림 읽기

'알림 읽기'를 허용하면 동계부가 토스·카카오페이의 결제 알림에서 위 내용을 꺼내 '가계부에 등록할까요?' 하고 물어요.

- Android 는 알림 읽기를 허용한 앱에 기기의 모든 알림을 넘겨줘요. 동계부는 **어느 앱의 알림인지만 보고**, 토스·카카오페이가 아니면 바로 버려요. 다른 앱 알림의 내용은 읽지도, 저장하지도 않아요.
- 꺼낸 결제 내용은 묻는 알림과 알림 목록(홈 오른쪽 위 종)에 쓰려고 기기에 보관하고, **결제 시각에서 7일이 지나면 지워요.**
- 등록을 눌러 저장한 거래만 가계부에 남아요.

### 잠금과 지문

앱 잠금과 월급 잠금을 지문으로 열 때 지문 확인은 Android 가 해요. 동계부는 확인됐는지만 전달받고, 지문 정보는 받지 않아요.

### 개발자 모드 로그

문제가 생겼을 때 원인을 찾으려고 두는 기능이고, 처음에는 꺼져 있어요.

- 켠 동안에만 앱에서 일어난 일(오류, 결제 알림 처리, 거래 등록·수정·삭제, 업데이트, 화면 이동)과 앱 버전, 기기 정보(Android 버전, 제조사, 모델)를 이 기기의 앱 전용 폴더에 최근 1000건 남짓 남겨요.
- 결제 알림을 처리한 기록에는 금액·카드·가게와 토스·카카오페이 알림의 문구가 들어갈 수 있어요.
- 끄면 쌓인 로그를 모두 지워요.
- 로그는 사용자가 개발자 모드 화면에서 **직접 복사해 보낼 때만** 기기 밖으로 나가요.

## 4. 백업

백업은 사용자가 직접 만들고 보관하는 파일이에요. 개발자에게 보내지 않아요.

- 백업에는 거래·분류·결제수단과 월급 설정이 들어가요. 화면 테마·자동 기능 설정, 결제 알림 목록, 잠금 PIN 은 들어가지 않아요.
- **JSON으로 복사**: 백업을 글로 바꿔 클립보드에 넣어요. 붙여 넣는 곳은 사용자가 정해요.
- **파일로 내려받기**: 기기의 다운로드 폴더에 `동계부-백업-날짜.json` 파일로 저장해요.
- **자동 백업**: 정한 주기(처음에는 1주마다)가 지났으면 앱을 열 때 다운로드 폴더에 `동계부-자동백업-날짜.json` 으로 저장하고, 자동 백업 파일은 **최근 3개만** 남기고 지워요. 설정 > 백업에서 끌 수 있어요.
- 복원이나 데이터 초기화로 지금 데이터를 지우기 전에도 다운로드 폴더에 백업 파일을 먼저 저장해요(`…-복원전.json`, `…-초기화전.json`). 고급 설정에서 끌 수 있어요.
- 다운로드 폴더의 파일은 앱을 지워도 남고, 파일 관리자 등 기기의 파일에 접근할 수 있는 앱에서 보일 수 있어요. 필요 없으면 직접 지워 주세요.

### Android 자동 백업

기기 설정에서 Google 백업이 켜져 있으면, Android 가 앱 데이터 일부를 사용자의 Google 계정에 백업하고 새 기기로 옮길 때 되살려요.
이건 동계부가 보내는 것이 아니라 Android 기능이고, 개발자는 그 내용을 볼 수 없어요. 기기 설정에서 끌 수 있어요.

- 백업되는 것: 가계부 데이터베이스(거래·분류·결제수단)와 설정 파일(화면 테마 등 설정, 월급 설정)
- 백업되지 않는 것: 잠금 PIN, 결제 알림 기록, 개발자 모드 로그, 그 밖의 기록

## 5. 인터넷을 쓰는 곳

동계부는 두 가지로 배포돼요. 어느 쪽이든 가계부 내용을 보내지 않아요.

- **GitHub 에서 받은 앱**: 새 버전이 있는지 GitHub(api.github.com)에 묻고, 새 버전을 설치할 때 GitHub 에서 설치 파일(APK)을 내려받아요.
  이때 GitHub 는 여느 접속처럼 기기의 IP 주소 등 접속 정보를 받아요. 이 정보는 [GitHub 개인정보처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)을 따라요.
  '앱을 열 때 새 버전 확인하기'를 끄면 앱 정보에서 직접 확인할 때만 물어요.
- **Google Play 에서 받은 앱**: 인터넷 권한이 없어요. 새 버전이 있는지는 기기의 Play 스토어 앱에 묻고, 내려받기와 설치는 Google Play 가 해요.
  이 과정은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따라요.

이 문서나 GitHub 배포 페이지를 여는 링크는 사용자가 누를 때 기기의 브라우저로 열려요.

## 6. 권한과 쓰는 곳

| 권한 | 쓰는 곳 |
| --- | --- |
| 알림 읽기 | 토스·카카오페이 결제 알림을 읽어 가계부에 등록할지 물을 때. 사용자가 기기 설정에서 허용해야 해요 |
| 알림 보내기 | '가계부에 등록할까요?' 알림과 월급날 '월급 들어왔나요?' 알림 |
| 생체 인증 | 앱 잠금·월급 잠금을 지문으로 열 때 |
| 부팅 완료 알림 받기 | 기기를 다시 켜면 사라지는 월급날 알람을 다시 맞출 때 |
| 인터넷 (GitHub 에서 받은 앱만) | 새 버전 확인과 내려받기 |
| 앱 설치 요청 (GitHub 에서 받은 앱만) | 내려받은 새 버전을 설치할 때. 사용자가 '출처를 알 수 없는 앱 설치'에서 허용해야 해요 |

백업 파일은 Android 의 다운로드 폴더 기능으로 저장하고, 복원할 파일은 사용자가 시스템 파일 선택 창에서 고른 것만 읽어요. 그래서 저장 공간 권한을 따로 받지 않아요.

## 7. 보관 기간과 지우기

정보는 사용자가 지울 때까지 이 기기에만 있어요. 가계부 내용은 앱에서 직접 보고, 고치고, 지울 수 있어요.

- **거래 하나씩**: 거래 상세에서 지워요.
- **데이터 초기화**(설정 > 고급 설정): 거래·분류·결제수단을 처음 설치한 상태로 되돌리고, 월급 설정과 월급 잠금을 지우고, 알림 목록을 비워요.
- **앱 삭제**나 기기 설정의 **저장공간 > 데이터 삭제**: 이 기기에 있는 동계부의 데이터가 모두 지워져요. 다운로드 폴더의 백업 파일은 남아요.
- **결제 알림 기록**: 결제 시각에서 7일이 지나면 저절로 지워져요.
- **개발자 모드 로그**: 개발자 모드를 끄면 지워져요.
- Google 계정에 백업된 데이터는 기기 설정이나 Google 계정에서 관리해요.

개발자는 사용자의 데이터를 받지 않으므로 대신 보거나 지워 드릴 수 없어요.

## 8. 아동의 개인정보

동계부는 아동을 대상으로 만든 앱이 아니에요. 다만 누구의 개인정보도 기기 밖으로 수집하지 않으므로 아동의 정보도 수집하지 않아요.
